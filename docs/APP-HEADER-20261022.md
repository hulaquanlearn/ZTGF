# 安卓 App 1.0.3 单顶栏与更新提示 · 2026-10-22

用户提供手机截图，指出原生绿色“智题工坊／更多”栏与网页账号顶栏重复；随后要求参考情侣 App 将更新放在登录后，并在发现新版时提醒用户。

## 实现

- 删除 `MainActivity` 的原生 toolbar、标题、更多按钮、更新按钮、PopupMenu 和仅服务于旧顶栏的辅助方法；首页入口沿用网页品牌与底部导航。
- 只保留网页顶栏，直接显示账号名称。原生刷新、账号密码、应用更新、服务器、浏览器和关于操作，通过 App 内置 `app-controls.js` 添加到当前账号菜单；仍使用限定主文档与服务器来源、每文档独立 nonce 的消息端口，没有新增 JavaScript 原生对象接口。
- 登录页仅提供保存／显示密码与“App 设置”（账号密码、服务器地址）。没有应用更新按钮或安装提示；账号菜单中的更新入口只在登录状态创建，退出登录后移除。
- 静默获取版本后，已登录且在前台时发现更高 `versionCode`，显示原生“立即更新／稍后”提示。`UpdateReminder` 按当前服务器、同一次 App 打开、安装包地址去重；点稍后不反复打扰，菜单保留“有新版本”，手动检查仍可再次打开提示。更换服务器重置提醒范围。
- 安装仍由浏览器下载与安卓系统确认；不静默安装，不强制重启或清空表单。网络页面更新在同一账号菜单“刷新页面 · 有新内容”提示。
- 系统栏与页面采用米白色，支持深色图标的平台使用深色图标；Android 8.0 的底部系统栏使用深底以保持白色图标可读。API 27 的浅色导航栏样式放在 `values-v27`，保留最低 API 26 支持。

只读核对情侣项目 `mobile-app/src/app/us.tsx` 的“应用更新”入口、`updates.tsx` 及 `AppFrame.tsx` 的登录后提醒，不修改该项目。
