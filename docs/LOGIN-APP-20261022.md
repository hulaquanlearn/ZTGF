# 2026-10-22 登录与账号显示修正

## 改动与清理

- 首页去掉账号欢迎区；右上角显示账号名称，手机保留名称；长名称省略并提供完整标题。
- 登录页密码框下增加明确的“显示密码”复选框。App 1.0.2 通过限定服务器来源、限定顶层文档的 WebMessagePort 启用同排“保存密码”。普通网页不保存密码，也不显示无法生效的保存选项。
- 默认不保存，仅勾选且成功登录后保存提交的账号密码；取消勾选清除记录，错误登录不保存。不把密码写入浏览器存储、URL 或日志；加密与服务器隔离沿用 Android Keystore。
- 安装包更新在原生 App“更多 → 检查 App 更新”；页面新内容在原生刷新菜单标识。移除网页账号菜单的下载入口，直接 `/android/` 初装下载页保留。
- 删除无引用的旧登录脚本、主题、小猫图片及来源说明、旧动效测试，共 5 个文件。生产样式清理 152 条旧登录、欢迎区与头像规则，其他 CSS 字节保留；历史包、回滚资料和业务数据保留。
