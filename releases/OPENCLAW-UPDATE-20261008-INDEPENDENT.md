# 2026-10-08 独立账号修正版更新说明

本包替代共享身份版：智题6.2.1、情侣2.19.13各自独立认证，只统一账号要求，不绑定、不同步密码、不创建身份库，用户自行设为相同。更新不修改现有凭据。

## 一、备份与更新

增量包针对智题6.1、情侣2.19.11起的本次修改。现场有其他改动先比对MANIFEST。确认3080实际PM2目录/入口/进程名，备份两项目源码、.env、数据库和媒体。将quizforge/和couple-space/清单文件分别复制到对应项目，不跨项目覆盖、不删除业务数据、不以schema.sql重建数据库。不覆盖.env；两个服务目录 npm ci --omit=dev 后重启正确进程。本次无新增依赖；智题仅新增corpus_entries，情侣业务schema不变。

勿部署旧身份进程、勿运行provision脚本、勿开3090端口；本版不调用IDENTITY_URL/IDENTITY_CLIENT_KEY。如意外配置过，先备份、确认本地账号能登录再停用专用身份进程，保留所有数据库。情侣index.wxml需开发者工具上传发布；仅重启后端不会更新小程序。保持情侣原HTTPS。

## 二、账号规则及验收

新账号非空、无最短长度和字符组合要求，统一最多40字符（情侣原数据库容量），不截断账号。新建/重设密码至少6位、不强制字符组合，旧短密码仍可登录。账号沿用大小写不敏感匹配。智题已有41至60字符账号兼容登录，不新增此长度账号。不改业务ID或couple_id、不直接覆盖密码哈希。两项目各自保存密码和会话，改密互不影响。用户自行修改，不代为修改。

验收健康接口version=6.2.1、identityMode=standalone，原账号独立登录；雅思下面有语料库，四分类可查看编辑，网址无#且/corpus刷新正常。新建1字符账号和6位密码成功，5位新密码失败。不同账号私有数据仍隔离。

## 三、网址及手机

智题用户入口 `http://49.234.185.199:3080/`，页面路径 /login、/english、/ielts、/corpus、/settings 不再有 #。旧 /#/ 链接会转为普通路径。Express 已处理深层页面刷新；如果前面还有Nginx，3080相关页面请求必须转发到本次Node服务，不能对 /corpus 返回静态404，也不能把 /api 的错误请求改写成网页。

手机验收：320/375/390宽度下导航展开收起、语料四项横排、查看完整内容、滚动编辑表单并保存、取消、题量设定及选择题操作；实际 iOS Safari / Android 浏览器至少各验证一次，切换横竖屏与软键盘后保存仍可点击。本地模拟宽度验证不等于真实设备已验收。

注意 HTTP 不是加密连接，密码至少6位只是统一最低规则，不是公网安全保障。保留用户要求的IP/端口访问，可另经VPN/安全隧道或有效TLS保护，禁止因此公开身份服务或关闭已有情侣HTTPS。

## 四、OpenClaw 必须补充的题目和学习资料

这里的“补充内容”是增加实际词汇、练习题、阅读资料、听力文本、写作示例与口语素材，不是仅写功能说明。部署并确认目标账号后开展，不能写入任意第一个用户或泄露另一人的资料。

第一阶段目标（属于原创学习材料，不冒充官方真题/词表）：

- 英语基础与考研专题：先盘点现有4929词/用户上传是否已入库，保留原来源；缺基础内容时补充500条常用词汇（英、中、词性、例句与释义），不以重复释义凑数。考研5500必须以用户提供/有授权的大纲词单核对；不能声称自动生成就是完整官方5500。
- 雅思词汇：补充500条常用学术/生活词汇，覆盖教育、环境、科技、健康、城市与工作等主题。每条有英中释义、原创新例句、来源标记及难度。
- 阅读语料20条：标题、完整英文短文、中文释义、重点表达/例句、标签、来源；另制作不少于100道英语/雅思客观阅读练习，题组共用原文，选项、标准答案与解析完整，不拆散题组。采用项目已有题库 schema。
- 听力语料20条：场景对话/独白、转写、中文释义、关键信息、学习建议；文字材料明确标记“听力文本”，没有音频不能称已提供听力音频。本版语料库未新增音频上传。可以补充带明确答案的填空/选择题；数词、拼写、可接受备选答案须人工核对。
- 写作语料30条：Task1/Task2任务说明、观点/结构、实用表达、原创参考段落/范文、中文解释和自查要点。参考范文不是唯一标准答案，不做规则自动评分或编造雅思分数。
- 口语语料30条：Part1/2/3话题、示范表达、核心词组、展开思路、中文解释与练习提示。不是机器评分，不把同义表达判为唯一错对。

数据流程：先产生内容 JSON 草稿 → 人工/来源核对 → 只将明确正确的标准答案用于规则判分 → 设置 reviewed:true → 分批导入指定账号 → 报告实际新增/重复/待审数量。不得抓取墨墨私有内容、盗版教材或绕过导出限制；使用用户合法资料、许可明确的资料及原创练习，保留出处与许可，不伪造官方/满分标识。找不到来源/答案不能可靠核实时保留草稿并报告，不擅自发布。

模板见 server-content-template.json；示例占位不是可发布学习资料。语料 category为reading/listening/writing/speaking。题库track为english/postgraduate/ielts/general，module为reading/listening等，客观题 answer 格式使用现有系统约定，choice 是从0开始的选项索引，填空需完整标准答案/允许备选，分组题保留groupId/materialText。

导入脚本：在服务器智题根设置 LEARNING_ACCOUNT、LEARNING_PASSWORD（用户提供）、LEARNING_EXPECTED_USER_ID（核对后的原智题UUID），然后 `node scripts/import-learning-content.js /安全暂存目录/复核后的内容.json`。默认仅调用本机3080 API；其他本机端口可设LEARNING_BASE_URL。该脚本不直接操作数据库，不合并用户，不覆盖既有同名不同内容语料；同名题库会拒绝，需要人工核对。词汇由现有API去重。每批导入不是跨资源全局事务，若中途中断，先检查已新增条目与脚本结果，避免整批重复重跑；保存草稿、复核记录及新增清单，不删除原资料。用后删除临时密码环境变量。

验收：目标用户能搜索并查看新增语料，按实际词库能抽20/50题而非固定8题，题目标准答案和分数正确、另一个账号看不到私有内容，中文/英文无乱码。不要修改用户已有答题成绩。若所选词库只有8词，需补词库，不得重复题凑50；每轮最大200为性能保护，可分多轮学习。
