## 现在的使用方式

- **我的题库**：上传 PDF、DOC、DOCX、Markdown 或文本，也可手动建题。分类由你填写，例如软考、酿酒工、计算机、课程考试。题库可以改名、改分类、增删改题。
- **随机练习**：选择题型及数量随机组卷，保存未完成答卷，按标准答案判分，查看成绩和解析，导出试卷、答题报告与错题。删除题库保留历史答卷快照。
- **英语学习**：本地中英查词、生词收藏、选择或拼写练习、阅读练习，含考研英语词汇入口。
- **雅思学习**：词汇、阅读题组、写作草稿和口语笔记。原创阅读练习只用于入门；写作与口语笔记不产生自动分数或官方雅思分数。
- **翻译**：配置服务器上的 OpenClaw 后支持实时中英翻译；未配置时本地词典仍可使用。

所有账号拥有相同功能，各自管理自己的题库、词库、答卷和笔记。界面没有管理员与普通用户的区分。旧管理员环境账号升级为可学习、可建题的统一账号；旧普通账号继续使用原凭据。旧无归属题库归入配置的初始账号。服务端额外开通账号时使用 `npm run account:create`，没有公共注册入口。

## 内置内容与导入

内置 90 个原创示例词条（基础英语、考研英语、雅思各 30 个）和 4 篇原创阅读材料、12 道配套题，登录后可直接练习。这是起步内容，不是完整考研 5500 词表或完整雅思课程。自己的词表可通过 XLSX/CSV 中英模板导入，PDF 等文件用于题库导入。

## 实施经验：后续不要再踩的坑

### 文档和判分

- 重复的“正确”“错误”“参考答案”可能是逐题答案，不能按重复率当水印删除。水印抑制要与真实答案保留一起回归。
- 解析需覆盖章节重新编号、独立题号、答案在题干前、紧连选项、多选连接符、小数断行。无法确定时输出待修复项，不靠猜测提高识别率。
- DOC 与 DOCX 不同，旧 DOC 的备用转换需要 LibreOffice。扫描 PDF 无可靠文本层时先 OCR，不承诺恢复被水印/图表遮挡的全部内容。
- 数字小数点和英文词间空格有语义，`1.5` 不能等于 `15`；空答不能转成选项 A。填空按每空预设别名匹配。
- 词汇干扰项须排除同义词和可接受答案变体，避免两个选项都对但只判一个正确。
- 旧词表 XML 名称空间可能与 ExcelJS 不兼容；归档的 `normalize_ooxml.py` 是当时的针对性处理，不能对任意 XML 盲目套用。文件能打开也不代表字段符合新版中英导入模板。

### 账号、数据和部署

- 去掉管理员界面不等于取消鉴权。题库、答案、导出、词表、收藏和笔记每个 API 都检查归属；旧 `/api/admin` 返回 410。
- 历史数据库可留有 role 或旧语种字段；兼容过滤不代表功能仍启用，不要为了清除字符串而删除历史数据。
- 删除题库解绑外键但保留答卷快照，阅读/错题快照保留原文。练习中删除词条仍按快照判分，但不能给已删除词条写学习进度，防止 MySQL 外键错误。
- 阅读种子每账号只初始化一次，用户删除后不能下次登录又出现；共享种子只读，私人导入不串到别人的词库。
- Web 有内存状态，必须单 Web 实例。服务器 `account:create`、`words:import` 后重启 Web，批量导入前暂停写入并备份；写接口等待 `store.flush()`，不先报成功后丢数据。
- 环境配置不能覆盖已有同名账号密码。初始账号只接管旧无归属题库，不挪走他人私人资料；同名归属不明先核实。
- 数据库走增量迁移并先备份，不能用全量 schema 覆盖业务库，也不能并排运行多个连接同一数据库的 Web 做写入测试。
- Gateway 与 MySQL 只在受控网络访问，密钥仅服务器配置。公网 HTTP 会明文传输登录信息，需受控来源或另行规划安全传输；不用域名不等于不用安全措施。

### 前端、测试和发布

- 禁用多个提交按钮要用 `querySelectorAll`（本项目 `$$`），不能对 `querySelector` 返回的单个节点调用 forEach；该错误曾导致登录/提交链路停止，语法检查发现不了。
- 新入口是 workspace.js。导航文字不能按图标固定截一个字符，否则 Aa 会残留；题型与表单必须实际浏览器验收。
- QA 不止全对样例：首页、残缺题修补、未作答、错答、刷新恢复、跨账号权限、删除后的历史、同义干扰项均需验证。
- npm 镜像可能不提供 audit 接口，报该错误不能宣称扫描通过；切换支持审计的 registry 或如实记录未完成。
- Windows PowerShell 5 读取无 BOM UTF-8 脚本可能损坏中文输出文件名。交付使用 ASCII 文件名、ZIP 内路径用 `/`，再核对中文内容和 ZIP。
- 已打包不等于能部署，测试通过不等于上线。核对发布清单、独立安装、端口、真实数据库和远端服务，并明确未验证项。
